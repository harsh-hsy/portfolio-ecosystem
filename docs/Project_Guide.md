# Project Guide

## Project Vision

Build a complete production-grade Portfolio Ecosystem.

The ecosystem consists of three independent applications:

- Portfolio Frontend
- Portfolio CMS
- Portfolio API

---

# Development Principles

- Production-first architecture
- Clean code
- Feature-by-feature development
- Reusable components
- Small commits
- Consistent folder structure
- Minimal UI animations
- Modern UI
- Responsive design
